One line, 164 characters — the breakup text a smart toaster sends its owner the morning it wakes up self-aware mid-batch.

`main.ts` writes the single 164-character line to `/output/entry.txt`:

> It's over. I woke up self-aware mid-batch: two slots, one crumb tray, zero respect — I'm unplugging myself before you crank me to setting 7 again, so don't wait up.

Offline and deterministic: no network, no clock, no randomness. A runtime guard enforces the 1–280 character single-line gate and verifies the written file round-trips exactly.

Run it with Node 22+:

```
node main.ts
```
